# 使用说明

[返回首页](../README.md)

## 启动

完成 [源码安装](../README.md#快速开始) 后，在项目根目录运行：

```powershell
.\.venv\Scripts\python -m chi_generator.main
```

旧入口 `python -m opeis_master.main` 仍转发到同一应用。Windows 打包与分发见 [打包说明](packaging.md)。

## 基本流程

1. 选择「序列」或「脉冲」模式。
2. 填写方案名称、文件前缀和导出目录。
3. 确认 1C 基准，选择倍率或绝对电流输入。
4. 配置工步、电压窗口、等待时间、取点与采样间隔。
5. 设置阻抗参数。
6. 检查总览、采样看板、警告与错误及极简脚本。
7. 修正错误；若存在高风险警告，确认后点击「复制极简脚本」。
8. 将脚本粘贴到 CHI Macro Command，在 CHI 中检查并运行。

## 工作区与项目

![工作区、项目、电池与电流设置，以及右侧风险和脚本预览](../image/1.png)

左侧设置实验参数，右侧展示总览、警告与错误、采样看板和脚本预览。截图展示操作区域，具体字段以当前界面为准。

| 模式 | 用途 |
| --- | --- |
| 序列 | 将时间、电压、DOD、静置工步从上到下组合执行 |
| 脉冲 | 按弛豫、脉冲和前后 EIS 的流程执行，可追加电压放电段 |

工作区支持「新建」「打开」「保存」「另存为」和最近预设。预设文件为 `.chi-preset`，保存的是界面参数，需在应用中重新生成脚本。

| 项目字段 | 作用 |
| --- | --- |
| 方案名称 | 帮助辨认方案，显示在摘要中 |
| 文件前缀 | 用于生成各段保存文件名，每次实验应使用不同前缀 |
| 导出目录 | 写入 CHI 的 `folder=` 命令；留空时使用 `.` |

导出目录指 CHI 运行脚本时保存测量文件的位置。脚本使用 `fileoverride`，重复执行同名文件会覆盖原数据。

## 电池与电流

| 1C 换算方式 | 需要输入 |
| --- | --- |
| 按材料理论容量 | 活性物质量（mg）、理论比容量（mAh/g） |
| 按已知倍率电流 | 已知倍率（C）及对应电流（A） |

选择倍率输入时，软件将倍率换算为安培；选择绝对电流时，直接填写电流大小。充电和放电通过方向选择，电流填正数，由软件处理符号。

例如，材料基准下 `1 mg × 865 mAh/g = 0.865 mAh`，对应 `1C = 0.000865 A`，因此 `0.1C = 0.0000865 A`。这是换算示例，实际参数需按样品设置。

## 工步与取点

序列按工步列表从上到下执行。每个受控工步分别设置方向、电流、电压窗口、采样间隔，以及是否在每个点后插入 EIS。连续工步可以组成循环块重复执行。

### 时间工步

![时间工步：方向、电流、分段取点与时间基准设置](../image/2.png)

时间工步用恒流 `ISTEP` 段推进实验，在累计时间点后插入 EIS。

| 取点方式 | 设置 |
| --- | --- |
| 固定 | 总时长与固定间隔，或总时长与固定点数 |
| 分段 | 为各段分别设置时长和点数 |
| 手动 | 输入严格递增的累计时间列表 |

例如，在手动模式输入 `20, 40, 60 min`，表示累计到这些时间点后测量，而不是每段分别运行这么久。

| 时间基准 | 含义 |
| --- | --- |
| 按有效进度 | 取点按恒流有效运行时间推进，EIS 和等待额外增加总历时 |
| 按中断补偿 | 根据累计中断时长调整后续恒流段 |
| 按等效容量补偿 | 按模型估算的 EIS 容量消耗缩短恒流保持时间 |

补偿依赖 EIS 时长或容量消耗估算，并非对实际实验进度的在线校正。使用补偿时应检查摘要中的时长、偏移和风险提示。

### 电压工步

![电压工步：范围生成、方向、电流和电压窗口设置](../image/3.png)

电压工步用恒流 `CP` 段到达目标电压。点位可按起始、结束、正步长生成，也可手动输入单调列表；放电通常由高到低，充电由低到高。

| 方式 | 到达电压点后的行为 |
| --- | --- |
| 目标电压 PEIS | 用 `ei=<目标电压>` 测阻抗 |
| 电压弛豫 EIS | 按触发后静置时间等待，再用 `eio` 读取当前开路电位测阻抗 |
| 手动初始电位 | 使用工步中指定的 EIS 初始电位 |

工步自己的 EIS 初始电位策略优先于全局阻抗设置。目标电压测量与弛豫后测量表示不同状态，应按实验目的选择。

CP 的实际耗时取决于电池响应，软件无法精确预测。含这类工步的总历时可能未知，后续 SoC 预测也可能不完整。

### DOD 准原位 EIS

DOD 表示放电深度。填写严格递增、最高为 `100%` 的点位列表，选择理论容量、用户参考容量或无 EIS 对照容量作为基准。

软件按容量与电流换算各点的恒流运行时间，随后静置并使用 `eio` 测量。点位是基于输入容量的计划值；如果电压提前到达截止边界，实际过程可能无法完成全部点位。不同 DOD 工步的容量基准冲突时会阻止生成。

### 静置与循环

![独立静置工步：设置静置时长](../image/4.png)

静置工步是独立的休息阶段，不充放电，也不生成 EIS 点。「点前等待」则作用于受控工步中的每个点，两者用途不同。

需要重复「放电 → 静置 → 充电」等组合时，先建立工步，再将连续工步组成循环块。

## 阻抗参数

![阻抗参数：初始电位、FT 或 SF、频率范围、振幅和静置时间](../image/5.png)

| 参数 | 作用 |
| --- | --- |
| 开路电位 / 手动初始电位 | 指定一般 EIS 段的初始电位；电压与 DOD 工步按各自策略处理 |
| FT / SF | 对应 `IMPFT` / `IMPSF` 测量命令 |
| 高频 / 低频（Hz） | 设置频率范围，高频必须高于低频 |
| 电压振幅（V） | 设置交流扰动振幅 |
| 静置时间（s） | 设置阻抗测量前的 `qt` 等待时间 |

低频越低，单次 EIS 通常越长。尤其是 `0.01 Hz` 与密集取点组合时，应先检查历时估算和风险提示。

## 脉冲模式

切换到「脉冲」，设置静置或恒流弛豫、弛豫时长、脉冲电流、脉冲时长、重复次数、采样间隔和电压窗口。电流支持倍率或绝对电流输入。

每轮包含弛豫、脉冲前 EIS、脉冲和脉冲后 EIS。可开启「脉冲结束后追加电压放电段」，设置尾段电流、电压点及是否逐点插入 EIS；尾段在所有脉冲结束后执行一次。

## 风险提示与复制

| 提示 | 行为 |
| --- | --- |
| 错误（Error） | 不生成可复制脚本，需先修正输入 |
| 普通警告（Warning） | 显示提示，允许复制 |
| 高风险警告 | 点击「我已确认高风险，允许复制」后才能复制 |

修改参数后需要重新确认高风险设置。常见提示包括低频测量过长、EIS 频繁中断、SoC 可能耗尽、充放电切换频繁和静置过长。

右侧只展示摘要与极简脚本。摘要、估算和警告不会进入复制出的 CHI 命令。

## 输出约定

- 头部：`fileoverride`、`folder=...`、`cellon`。
- 恒流时间段：`tech=istep`；目标电压段：`tech=cp`。
- 阻抗段：`tech=imp`，随后使用 `impft` 或 `impsf`。
- 保存名自动区分工步及 `CC`、`EIS`、`REL`、`PULSE` 等类型。
- 结尾：`celloff`、`end`。

最终脚本不含计算公式、说明或调试文本。设备连接、脚本运行和数据检查都在 CHI 中完成。
